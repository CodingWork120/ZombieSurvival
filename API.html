API TOKENS

Time - API TOKENS are generated during a specific time. If you have a source that provides a API TOKEN, then you must get another API TOKEN every interval event. This interval event is kept a secret for safety reasons.

Format - If you every used a API TOKEN, you have realized a similar pattern. API TOKENS will always have a closing API STRING, and a starting API STRING so the system can detect the attempted API TOKEN, this allows the system to check the API token without breaking.

API Source - A API source is provided to trusted members of the claim (The actual Game / Program) the API is use in. API SOURCES will be a sort of generator that provides a API TOKEN as per the interval. This gives the API SOURCE owner full control over who has access, and who doesn't.
